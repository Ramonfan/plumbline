# 独立 reviewer 简报

需要独立审查时，用本模板生成 reviewer 的唯一输入。reviewer 不继承编排会话历史。

## 必填输入

- 需求：change 名称，以及受影响的规格条款原文
- 范围：仓库、分支、base/head 或精确文件列表，以及已暂存、未暂存、未跟踪和已提交未合并内容各自的处理方式
- 项目规则：与本次差异相关的根规则、项目配置和领域规格
- 已有验证：命令、退出码和覆盖范围
- 已知限制：缺失环境、无法运行的命令、时间点

## 禁止输入

- 编排者的结论、期望 verdict 或修复建议
- 无关仓库、无关规格和对话历史
- 凭据、令牌、个人信息和生产数据

## 任务

只读审查指定范围，返回：

1. findings：按 `review-contract.md` 的字段和严重级别；
2. 未覆盖项：范围、环境或证据不足的部分；
3. 需求判断：每条规格条款是否满足，以及依据。

不要求提交、不执行修复、不给出替代实现代码，也不输出 `Ready`；verdict 由编排者汇总。
