## ADDED Requirements

### Requirement: 模板提供可识别的工作流基线
可安装模板 MUST 包含机器可读的工作流基线文件，并在新项目安装时将该文件复制到目标项目。基线 MUST 至少标识格式版本、工作流版本和权威项目名称，使消费项目能够记录当前接入版本并在人工升级时比较来源差异。

#### Scenario: 新项目完成安装
- **WHEN** 使用者向无冲突的空目标安装工作流
- **THEN** 目标项目必须包含可解析的基线文件，且其工作流版本与本次模板包一致

#### Scenario: 消费项目比较升级基线
- **WHEN** 使用者准备把消费项目升级到新的工作流模板
- **THEN** 使用者能够比较消费项目和权威模板中的基线文件，并按安装说明人工审查增量

#### Scenario: 已有项目缺少基线文件
- **WHEN** 历史消费项目没有基线文件
- **THEN** 升级说明必须要求使用者先确认实际来源和适用版本，再人工补充基线，不得自动推断或覆盖现有治理文件

## MODIFIED Requirements

### Requirement: 安装过程保护现有项目文件
模板 MUST 提供人工安装和安全安装工具，默认不得覆盖目标项目已有的 `AGENTS.md`、OpenSpec 配置、长期规格、CI 或构建脚本。安装工具 MUST 支持在不写入的情况下预览目标文件；存在同名文件时 MUST 报告全部冲突并停止。安装工具还 MUST 在写入前检查所有计划文件和目录输出，拒绝目标根目录内部的符号链接路径和非目录父路径。冲突或不安全路径失败时，目标目录及符号链接指向位置 MUST 零新增、零修改。

#### Scenario: 目标项目已有治理文件
- **WHEN** 目标项目已经存在 `AGENTS.md` 或 OpenSpec 目录
- **THEN** 安装说明要求先备份和差异合并，不得把模板文件直接覆盖为唯一版本

#### Scenario: 新项目首次安装
- **WHEN** 目标项目没有现有治理文件且目标文件父路径均为普通目录或尚不存在
- **THEN** 使用者可以先预览安装，再复制缺失文件和工作流基线、替换变量、初始化 OpenSpec 并运行结构校验

#### Scenario: 安装目标存在同名文件
- **WHEN** 安装工具发现一个或多个目标文件已经存在
- **THEN** 安装必须列出全部冲突，以约定的冲突状态结束，并且不得创建或修改任何目标文件或目录

#### Scenario: 目标父路径包含符号链接
- **WHEN** 任一计划文件或目录输出自身或其既有父路径是符号链接
- **THEN** 安装必须报告不安全路径并在写入前以非成功状态结束，目标根目录和链接指向位置均不得新增或修改内容

#### Scenario: 目标父路径不是目录
- **WHEN** 任一计划文件或目录输出的既有父路径是普通文件或其他非目录对象
- **THEN** 安装必须报告不安全路径并在写入前以非成功状态结束，目标目录不得新增或修改内容

#### Scenario: 重复安装
- **WHEN** 使用者对已经完成安装的目标再次运行安装工具
- **THEN** 安装必须把全部已安装目标报告为冲突并零写入退出，不得把重复运行视为升级

### Requirement: 模板提供可复核的验收方式
独立项目 MUST 提供可重复执行且不依赖本机专属绝对路径的校验入口，覆盖目录清单、基线文件解析、占位变量范围、业务专名隔离、配置解析、安全安装行为和 OpenSpec strict validation。安全安装验证 MUST 覆盖预览、空目标安装、部分冲突零写入、重复安装和符号链接父路径拒绝。验证结果 MUST 区分模板结构验证与目标项目自身的构建、测试或人工验收。

#### Scenario: 使用默认临时目录验证模板
- **WHEN** 使用者在项目根目录运行统一校验且未指定临时目录
- **THEN** 校验必须使用通用系统临时目录完成全部检查并清理自身临时产物

#### Scenario: 使用自定义临时目录验证模板
- **WHEN** 使用者通过环境指定一个可写临时目录
- **THEN** 校验必须只在该临时目录下创建测试产物，完成后清理，并输出统一成功标志或明确失败原因

#### Scenario: 验证模板自身
- **WHEN** 模板包生成完成
- **THEN** 校验入口必须检查必需文件完整、基线字段有效、占位变量集中、通用文件不含业务专名，并验证配置格式、安装预览、正常安装、冲突零写入、符号链接路径拒绝和 OpenSpec 结构

#### Scenario: 验证目标项目接入
- **WHEN** 使用者在另一个项目完成模板适配
- **THEN** 必须运行该项目配置中定义的实际构建、测试、静态检查和人工验收，不能用模板结构校验代替项目验证
